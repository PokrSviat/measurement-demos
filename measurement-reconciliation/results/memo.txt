Operating characteristics
Fresh draws of this generator, 300 seeds per row, the same experiment interval and the same cap test. The planted effect is set so the true cost is the row value.
- true cost 0.03: scale in 86%, the interval covers the truth in 93% (Monte Carlo standard error 1.5%).
- true cost 0.05: scale in 29%, the interval covers the truth in 93% (Monte Carlo standard error 1.5%).
- true cost 0.08: scale in 6%, the interval covers the truth in 93% (Monte Carlo standard error 1.5%).
- true cost 0.10: scale in 3%, the interval covers the truth in 93% (Monte Carlo standard error 1.5%).
- true cost 0.12: scale in 1%, the interval covers the truth in 93% (Monte Carlo standard error 1.5%).
- true cost 0.15: scale in 1%, the interval covers the truth in 93% (Monte Carlo standard error 1.5%).
A tactic at true cost 0.05 is scaled in 29% of draws, and a tactic above the cap in at most 1%. The lower-bound rule buys protection against funding a tactic above the cap with missed tactics below it. The misses come from the width of the experiment interval, so the size of the test, not the cap, is what would change them.
Coverage is 93% in every row. The rows reuse the same 300 seeds and plant an additive shift, so the interval moves with the truth and coverage cannot differ. That rate sits 1.4 standard errors from 95%.

What would overturn the scale decision
An experiment lower bound that is not strictly positive, or a cost at that bound that crosses the cap. A model that leaves the experiment interval uses the disagreement sentence and the same bound.
